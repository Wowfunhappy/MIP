MIP is a system for loading plugins which modify OS X apps. It was originally created by Lior Halphon, and has since been updated by Tanner Bennett, Banny, and zhkl0228.

After installing MIP, add plugins by copying .bundle files into:
	/usr/share/mip/Bundles/

After adding or deleting a plugin, relaunch your apps for the changes to take effect.
